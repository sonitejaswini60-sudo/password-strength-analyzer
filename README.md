# Password Strength Analyzer

A beginner-friendly web project for the Thiranex task.

## Features
- Password length check
- Uppercase/lowercase check
- Number and special-character check
- Repetition/common-password detection
- Score from 0–100
- Strength levels
- Strong password generator
- Stronger password suggestion
- Responsive design
- No password is sent to a server

## Run
Open `index.html` in any modern browser.

## Technologies
HTML5, CSS3 and JavaScript (no external libraries).
